Использованные виджеты:

*  Scaffold: Основной виджет для структуры приложения, обеспечивающий AppBar и Body.
*  AppBar: Виджет для создания верхней панели приложения с заголовком.
*  Container: Виджет-контейнер, использованный для изменения цвета фона и общей компоновки.
*  Column: Виджет для вертикального расположения дочерних виджетов.
*  Row: Виджет для горизонтального расположения дочерних виджетов (иконки).
*  Text: Виджет для отображения текста.
*  ElevatedButton: Виджет для создания кнопки.
*  Icon: Виджет для отображения иконок.
*  SizedBox: Виджет для создания пустого пространства между элементами.

Изменение стилей и цветов:
•  Text виджеты:
  *  fontSize: Размер шрифта.
  *  fontWeight: Толщина шрифта
  *  color: Цвет текста. Цвета задавались с помощью Colors.deepPurple и также использовался способ задания цвета через     Color.fromARGB.
