Созданные Экраны:
1. Экран Загрузки (Splash Screen): Отображается при запуске приложения и предназначен для инициализации данных и отображения логотипа.
2. Экран Регистрации: Предоставляет пользователю возможность создать новую учётную запись, вводя необходимые данные (например, имя пользователя, адрес электронной почты, пароль).
3. Экран Входа (Login Screen): Позволяет зарегистрированным пользователям войти в систему, используя свои учётные данные.
4. Главный Экран (Main Screen): Центральный экран приложения, отображающий задачи и привычки пользователя на текущий день. Обеспечивает обзор текущих активностей и прогресса.
5. Экран Добавления Задачи: Предоставляет интерфейс для создания новых задач, позволяя пользователю выбрать нужный тип задачи.

Организация Навигации:
1. При запуске приложения отображается Экран Загрузки.
2. После завершения загрузки приложение перенаправляет пользователя на Экран Входа, если пользователь не авторизован, или сразу на Главный Экран, если пользователь уже вошёл в систему.
3. С Экрана Входа пользователь может перейти на Экран Регистрации для создания новой учетной записи.
4. С Главного Экрана пользователь может перейти на Экран Добавления Задачи, нажав на соответствующую кнопку.
