Отчет по практической работе №4

Цель работы: Создание простого Flutter-приложения, демонстрирующего обновление состояния с использованием виджетов StatelessWidget, StatefulWidget, ElevatedButton, Text, Column, Row, Center и обработку событий onPressed и onLongPress.

1. Используемые виджеты:

•   MaterialApp: Корневой виджет приложения, устанавливающий тему оформления и домашнюю страницу.
* Scaffold: Обеспечивает базовую структуру приложения с AppBar и Body.
•   AppBar:  Верхняя панель приложения с заголовком ("Практика 4").  Использован виджет Text для отображения заголовка.
•   Center:  Центрирует дочерний виджет.
•   Column:  Размещает дочерние виджеты вертикально. Используется для организации текста и кнопок.
•   Row:  Размещает дочерние виджеты горизонтально. Используется для расположения кнопок "Add" и "Clear" в ряд.
•   Text:  Отображает текстовые строки. Использован для вывода заголовка "Значение счетчика:" и текущего значения счетчика. Стиль текста (размер шрифта) настроен через свойство style.
•   ElevatedButton:  Кнопка с возвышением.  Использована для кнопок "Add" и "Clear".  Стиль кнопок (цвет фона) задан через ElevatedButton.styleFrom. Также использован Icon в качестве дочернего виджета для отображения иконок.
•   Icon: Используется для отображения иконок.
•   SizedBox:  Используется для создания пустого пространства между виджетами.
•   StatelessWidget (MyApp): Представляет неизменяемую часть приложения, которая не зависит от изменяющихся данных. Используется в качестве корневого виджета.
•   StatefulWidget (MyHomePage): Представляет изменяемую часть приложения, которая может перерисовываться при изменении данных. Используется для страницы с счетчиком и кнопками.

2. Реализация обновления состояния:

Обновление состояния реализовано с использованием виджета StatefulWidget (MyHomePage) и его связанного класса State (_MyHomePageState).

•   _MyHomePageState:
    *   Содержит приватную переменную _counter, которая хранит текущее значение счетчика.
    *   Определяет методы _incrementCounter(), _clearCounter() и _addTenCounter() которые изменяют значение _counter.
    *   Вызов setState(() { ... }); внутри этих методов сообщает Flutter, что состояние виджета изменилось, и необходимо перерисовать виджет.

•   Механизм setState():
    *   Когда вызывается setState(), Flutter помечает виджет как "грязный" и планирует его перерисовку.
    *   В процессе перерисовки вызывается метод build() виджета _MyHomePageState, который создает новое дерево виджетов на основе обновленного значения _counter.
    *   Flutter сравнивает новое дерево виджетов со старым и обновляет только те части пользовательского интерфейса, которые изменились.  Это обеспечивает эффективное обновление только необходимой части экрана.

3. Обработка событий:

•   onPressed: Обработчик нажатия на кнопку.  Метод _incrementCounter() вызывается при обычном нажатии на кнопку "Add", а метод _clearCounter() вызывается при нажатии на кнопку "Clear".
•   onLongPress: Обработчик долгого нажатия на кнопку.  Метод _addTenCounter() вызывается при долгом нажатии на кнопку "Add".
•   Реализация:
    *   Свойства onPressed и onLongPress виджета ElevatedButton принимают анонимные функции (лямбда-выражения) в качестве значений.
    *   Эти анонимные функции вызывают методы _incrementCounter(), _clearCounter() и _addTenCounter(), которые обновляют состояние виджета и, как следствие, перерисовывают его.
